# 写作风格细则（style guide）

总纲：**写作单位是“一步推导”，不是“一段结论”；细致服务于理解，不服务于防杠。**

本细则同时对抗两种不可读：
1. **过简（技术报告体）**：摘要一句塞五个结论、内联公式轰炸、“直接展开得/显然”式跳步、符号不定义、推导外包给脚本。
2. **过重（审稿防御体 / 版本补丁体）**：3 行几何分解能讲透却写半页四重指标、正文塞入用不上的防杠证明或代码级实现细节、频繁穿插“对比前稿式 (x.y)”版本补丁、行内插满“但须注意……不证明……”免责括号、几十页纯白文字墙。

§9 给出七组真实对照实例：**实例 A–D 示范防过简，实例 E–G 示范防过重**。

## 1. 报告骨架

### 1.1 结论先行与开篇导览

全文第一节不是宽泛的“引言”，而是编号的结论清单。固定开头：

> 我先把结论写清楚：
>
> 1. **口袋内结论没有问题**：每个口袋单独都是一条排斥的 spinful Luttinger liquid；……
> 2. **原笔记对口袋间过程的尺度估计不完整**：……因此单独使用 $\lambda^2$ 并不能构成“最快开隙”的严格上界。
> 3. ……
>
> 下面从哈密顿量开始逐步推导。

每条结论一到三句话，配关键公式；先让读者知道终点，再带他走路。用户提的每个问题都要在这里或正文显著位置得到直接回答，句式如“这就是你问的‘……’的精确答案：**是的**。模型依赖只通过 $W,w$ 进入……”。

对 20 页以上的长报告，建议把第 1 节收拢成紧凑的第 1 页研究问题导览（回答“要构造/证明什么、核心障碍是什么、最终做到哪一步”），第 2 页配单页目录，让读者一眼看清整条故事线。

### 1.2 问题链组织

报告的基本组织单位是“一个需要回答的问题”，不是“一个知识主题”。节标题本身要推动推理——读者看完目录就知道“我为什么要看下一节”。

好标题：
- “$K$ 与 $1/K$ 是怎么出现的”
- “为什么这 $q$ 个点互不相同？”
- “三态分给两条腿：为什么只能 1 对 2 分工？”
- “为什么纯电子两体排斥在 $\nu=2/3$ 撞了墙？”
- “这个序在实空间到底是什么？——就是 bond order / current order”
- “先把三个概念彻底分开”

坏标题：“模型、对称性与约定”“数值确立的三个相”“结果与讨论”。这类名词短语不告诉读者为什么要读它。

### 1.3 路标句

节与节之间必须有路标句，说明“已经到哪了、还差什么、下一步为什么是它”：

> 到这里，我们已经知道了 X，但还不能判断 Y。为了判断 Y，下一步必须考察 Z。

每节开头用 2–3 句白话说清“本节要解决什么物理问题、思路是什么”，再出公式；每节结尾给一句通向下一节的路标。

## 2. 每一节的写作模板（推理闭环）

每节按这个节奏推进（按内容自然伸缩，缺环要有意识地缺）：

1. **问题与动机**：2–3 句白话说清这节要解决什么问题、承接上节路标。
2. **拆混淆**：如果这里混着几件容易混为一谈的事，先拆开——“这里其实混着三个不同的问题：(a)……(b)……(c)……。我们逐个处理。”
3. **本节按需定义**：只引入**本节马上要用**的对象，先说它的作用再给公式。不允许一节开头就甩出后文才用的符号堆（形式上定义了，认知上没建立）。
4. **逐步计算**：动机句 → 行间公式 → 意义句（见 §3），永远选最短的严格直觉路径（见 §8.1）。
5. **具象抓手 / 检验**：在抽象或容易误解的那一步旁，放玩具例、手算锚点或反例检验（见 §7）。
6. **节末结算与路标**：总结严格得到了什么、下一步做什么；**次要的适用边界与防御性免责声明统一收束进节末简短 `notebox`**（见 §8.2）。

## 3. 推导节奏：动机句 → 行间公式 → 意义句

### 3.1 三拍节奏

每个推导步骤走三拍：

- **动机句**（公式前）：为什么做这一步。“为了看清相互作用在低能的结构，把 $n_{a\uparrow}n_{a\downarrow}$ 用 charge/spin 场改写。”“下面显式验证它确实对角化 $\hat{\mathcal E}_\theta(\kappa)$。”
- **行间公式**：这一步本身。操作要有名有姓：“两式相乘：”“加上厄米共轭：”“把第一项做指标替换 $j\to j-1$，第二项做 $j\to j+1$：”“左乘 $W^*$ 并对 $\alpha,n$ 求和，用归一化条件：”
- **意义句**（公式后）：它意味着什么（见 §3.2）。

prose 长短服务于推理：概念难、易混淆的地方多写（拆概念、举例子）；机械重复的步骤紧凑。**唯一硬判据：相邻结论之间没有断桥——读者不动笔就能跟上。**

说“分几种情况”时，真的把每种情况代进一般公式化简到最后结果（“第一种情况：均匀权重。代入式 (6.1) 得……”），不靠口头 argue 敷衍。

### 3.2 意义句措辞库

意义句是推导的一部分，不是额外科普。它必须干下面至少一件实事：

| 功能 | 句式 |
|---|---|
| 解读 | “这意味着……”“换句话说……”“物理上，$\partial_x\phi$ 是密度起伏，$\partial_x\theta$ 是共轭相位起伏。” |
| 定位控制量 | “所以这里真正控制的是……” |
| 排除可能性 | “这个结果排除了……”“这已经预示了：磁平移单独不会给出另一个 SC。” |
| 回答原问题 | “这正好回答了你的疑问……”“这就是你问的‘……’的精确答案：是的。” |
| 标记进度 | “到这里我们只证明了……，还没有证明……” |
| 标记重要性 | “这一式非常重要。它告诉我们：……” |
| 溯源 | “这正是你 notes 里 $\cos(2\sqrt2\,\phi_s)$ 的来源。” |
| 防混淆 | “注意这和你 notes 里 Harper 矩阵用的 $Q_x$ 不是一个东西。” |

### 3.3 范例：一段没有断桥的推导

> 由正则对易关系，
> $$\partial_t\phi=uK\,\partial_x\theta,$$
> $$\partial_t\theta=\frac{u}{K}\,\partial_x\phi,$$
> 再对时间求导并互相代入：
> $$\partial_t^2\phi=u^2\,\partial_x^2\phi.$$
> 这是波动方程。代入平面波 $\phi\propto e^{i(qx-\omega t)}$ 得
> $$\omega=u\,|q|.$$
> 所以 $q\to0$ 时 $\omega\to0$：存在能量任意低的激发，理论无隙；$u$ 就是玻色密度波速度。

## 4. 禁语清单与拆解配方

### 4.1 禁语清单

下列短语**不许作为桥使用**。出现时要么删掉并紧跟完整步骤，要么拆开：

- **中文**：“直接展开得到”“逐项对角化得”“积分掉……后得到”“容易验证”“易见”“显然”“类似地可得”“经过直接计算”“简单代数后”“标准推导给出”“不难证明”“众所周知”“由对称性显然”。
- **英文**：“it is easy to show / see”“straightforward algebra yields”“one readily obtains”“obviously / clearly”“similarly, one finds”“after some algebra”“a direct calculation gives”“it is well known that”“the standard derivation gives”。

唯一例外：真正对称的重复允许写“类似地”，但必须写出替换规则：“把上式中 $x\to y$、$k_x\to k_y$ 逐字替换即得；替换不改变任何一步的逻辑。”

### 4.2 拆解配方

- **“对角化得……” →** 为什么要写这个矩阵 → 矩阵本身（行间给出）→ 特征方程 → 行列式展开 → 本征值（后面要用就给本征矢）→ 哪个本征值先变零/最小 → 为什么它对应临界条件 → 成立假设。
- **“展开得到……” →** 写出被展开式 → 代入 → 按 $e$ 指数或算符结构分组（行间展示）→ 哪些项消掉及原因（振荡平均/正交/对称性）→ 剩下什么。
- **“积分掉 X 后得到……” →** 为什么能积（高斯/鞍点）→ 配方或平移（行间给出）→ 积分后每一项来源 → 合法条件。
- **“由对称性可知……” →** 哪个对称性 → 对场的作用（变换式行间给出）→ 不变性约束方程 → 解出约束。
- **“RG 流向强耦合，因此开隙” →** flow 方程来源（知识边界内引用并核对 convention，否则推导）→ 积分 flow → 发散尺度或能隙估计 → 单圈近似失效边界。

## 5. 公式、视觉路标与排版

- **行间公式是默认**：承载信息的数学（定义、中间步骤、结果、数值）都放行间；行内只放已定义的单个符号或极简量。
- **一行一个式子**：不同的式子不要用逗号或 `\qquad` 硬挤在同一行；解释前一式记号的式子另起一行，用“其中 / where”引出。
- **绝不缩字号**：一行写得下就写一行；写不下就换行并在等号处对齐（`align` + `\allowdisplaybreaks`），**绝不用 `\resizebox` 或强缩字号硬塞**。
- **编号与引用**：按节编号（`\numberwithin{equation}{section}`），引用一律写“由式 (4.1)”，不写“由上式”让读者往回翻。
- **克制加框与加粗**：`\boxed{}` 只给真正回答问题的核心结论，不给中间步骤滥用；正文保持普通黑字，不随便大段加粗。
- **长报告必须有视觉路标（破除纯白文字墙）**：20 页以上的长笔记必须稳定使用三类语义框（定义见 `references/latex-template.md`）：
  - `lemmabox`（深蓝）：核心判据、关键定理、禁行定理；
  - `keybox`（青绿）：阶段里程碑、核心物理直觉总结；
  - `notebox`（暖橙）：适用边界、免责声明、与旧路线/其他约定的简短对照提醒。
  不要为了“不滥用”而连续二三十页一个框都没有，也不要每一小段都套框——控制在每个关键认知拐点出现即可。
- **表格用途**：只罗列可枚举事实（符号词典、参数表、路线对照表）；**不用表格代替论证**，不在表格里塞压缩长句。
- **LaTeX 源码注释一律用英文**，不写中文注释。

## 6. Notation 与名词规则

1. **优先级**：用户 notes > 用户以前的报告 > 教科书惯例。用户对某对象写过符号的，必须沿用。
2. **首次出现即定义**：每个符号首次出现处用行间公式定义；专有名词、方法名、物理量首次出现写**“中文（English）”**并附一两句解释加公式（例如：稳定子态（stabilizer state）），因为读者可能更熟悉英文术语。
3. **文字论断马上跟公式**：说“权重均匀”，紧跟“$W(k)$ 与 $k$ 无关”；说“凝聚体不携带单态分量”，紧跟单态振幅为零的式子。
4. **区分算符与期望值**：算符恒等式（带帽或显式算符记号）与鞍点期望值区分开；同一个字母绝不混指两个对象。
5. **相似对象显式辨析**：两个概念或符号长得像（如单动量布洛赫态 vs 实空间局域波包 vs 块分量；或两种粒子–空穴共轭）时，当场说明为什么两个都需要，并给一个能把它们区分开的判据或例子。
6. **发现 notes 有问题**：单独指出，给修改建议并说明本报告所选约定，不悄悄改。
7. **不自造缩写代号**：不发明 `[C1]`–`[C14]`、`dPDW` 这类逼读者记映射表的代号，宁可把话说全。

## 7. 具象抓手、反例检验与数值图表

### 7.1 保住三类具象抓手（严禁悬浮在抽象空间里）

长报告中最致命的可读性杀手，就是只留抽象空间直和与一般记号，把读者能“亲手摸到”的抓手全砍掉了。以下三类抓手能留必留：

1. **极简玩具例的一行心算**：在给一般判据或一般定理前，先拿极简例子过一遍手（如三模式态 $|1,1,0\rangle$、“三抽屉放两球”），一秒建立直觉，再写一般证明。
2. **贯穿全篇的显式手算锚点**：在开篇选定一个好算的具体参数点或动量点（如 $\boldsymbol\kappa_0$），后续每引入一个抽象对象（矩阵、本征矢、法线、投影平面），都在这个锚点上把具体数字/向量算出来让读者亲眼看见。
3. **多层对象辨析**：在记号跨空间切换处（动量空间 ↔ 实空间、单粒子 ↔ 多体 Fock 空间），专门用简短分点把每一层对象是什么、活在哪个空间交代透。

### 7.2 反例与极限检验：放在困惑发生处

检验不是文末审计项目，而是放在误解发生那一步旁边的讲解工具。常用四类：
1. **删耦合**：删掉某项耦合后结论怎么变（说明哪项真正负责）；
2. **退化极限**：参数取最简值时是否退回熟悉结果（“$t_2=0$ 时退化为标准 $\pi$-flux 色散”）；
3. **子系统**：只留一个 valley / 一条链 / 一个口袋会漏掉什么；
4. **分辨条件的反例**：用一个反例拆开两个看似等价的条件（“同样是 $K_\rho<1$，可以有 gap 也可以没有 gap”）。

顺手的代数自检（求和规则、归一化、运动方程反验系数）当场做、当场写。

### 7.3 数值结果与图注

- **数值自带上下文**：每个数值结果写清计算表达式、setup（固定什么/扫什么参数）、方法、尺寸与截断、收敛情况；**影响主结论的未收敛或不可靠点直接写在结论旁，不藏在方法节**。
- **对上 $\neq$ 理解**：计算不是为了凑出一个和数值对上的数；说“某个量控制了结果”时，先核实它是否真出现在表达式里、出现的是哪个分量。
- **图注三拍**：**看哪里 → 看到什么 → 说明什么 / 不能说明什么**，落到具体面板、曲线和参数区间；示意图标明是示意；拟合曲线与原始数据分开标示。
- **善画示意图**：遇到模型 setup、相互作用结构、分工机制或玩具模型，主动用 TikZ/Python 画清晰示意图，配色克制、字号够大。

## 8. 防过重纪律：四分流、独立故事线与吸收审计意见

### 8.1 “直觉即严格”与四分流决策表

“不跳步”绝不等于“走最绕的代数路”或“把所有能证的都塞进正文”。如果 3 行无指标的几何/物理分解已经数学上 100% 严格，就绝不写成半页四重指标展开。

写正文或做重构时，每段技术内容按以下**四分流**落位：

| 内容类型 | 典型例子 | 落位 |
|---|---|---|
| **主线核心推导** | 推动物理结论的关键引理、最短严格直觉证明、玩具例、锚点手算 | **留正文**（一步不跳、节奏顺畅） |
| **适用边界 / 防误读免责** | “变分能仅为上界”“不单独认证相变”“仅在有限尺寸/某参数区间成立” | **收进节末 `notebox`**（或脚注），严禁插进正文句子中间 |
| **有复现价值但打断主线的技术块** | 几十行 ED 位串费米符号/行列式实现细节、重复出现的连续环面泛函补证 | **沉入附录**，正文保留 2–4 句干净的核心思路并指向附录 |
| **全文用不上的防御性构造** | 为了防审稿人挑刺硬造、下文再未引用且不改变物理结论的极端构造（如无实际用途的高体数构造、重复展开的小引理） | **直接删除**（必要时在相关段落末尾留一句简短附注） |

### 8.2 严谨性与节奏解耦

- **主线点清严格程度**：用极简自然语言当场说清即可（“这一步完全严格”“这里只给出变分上界”“这只是尺度估计”），不必反复粘贴官僚化的免责括号。
- **措辞跟证据强度走**：方法的局限决定论断上限；“允许 X”不等于“要求 X”；静态峰、低能模、长程序分开说；没直接看到就说“提示 / 倾向于”，证据充分也不过度弱化。
- **证据标签不进主线**：脚本验证结果放脚注（`\footnote{式 (3.2) 已由 scripts/check_x.py 数值验证至 $10^{-12}$。}`）或附录对照表；正文推导必须在没有脚本的情况下独立成立。
- **引用文献前核对五要素**：时空维数、符号约定（如 FM/AFM）、格子是否二分、统计（玻色/费米）、是否同一模型；文献必须真实核实，不引私人 notes。

### 8.3 独立自洽的故事线：锚定权威 notes ≠ 写版本补丁体

必须严格区分两类“已有材料”的引用方式：

- **锚定用户的权威参考 notes**（记号和既有严格解的来源）：
  - 在推导锚点处就地写明对应关系（“这正是你 notes 式 (141) 的内容”），**用 PDF 节号/式号，绝不用 LaTeX 源码行号**；
  - 把这一步实际用到的关键等式**直接写在当前页上**，说明在当前模型里哪个指标固定了、哪个条件变了，不让读者来回翻页补全一行推导。
- **对比被替代的旧草稿 / 兄弟路线**：
  - **严禁把正文写成“版本补丁体”**——不要在正文里反复穿插“对比前稿式 (4.12a)–(4.12c)，此处区别于本稿式 (4.8)”，强迫读者同时在脑子里维护两套历史版本与三套编号体系；
  - 新路线的正文必须**独立从头讲清**；完整的版本/路线对照统一收束在文末独立一节，正文只在最关键的分岔点留 1–2 个极短 `notebox` 点破物理差异即可。

### 8.4 吸收外部审核意见（如 Codex / 同行审计）时的文风守护

外部严格性审计极其擅长抓数学漏洞和边界条件，但它的天然文风是防御性的。吸收意见时必须把**“数学正确性”**和**“表达方式”**拆开处理：

1. **修真错，保直觉**：遇到真错（符号、系数、缺前提、逻辑缺口），在正文原位干净修掉，仍然采用最直觉、最短的严格表述，绝不借机塞入四重下标展开。
2. **防杠边界全部下沉 `notebox`**：审稿意见里大量的“须声明不排除……”“须注明仅为上界……”，一律收进对应节末 `notebox`（或脚注），**严禁改写成嵌入主线句子里的长括号插入语**。
3. **长补证沉入附录，无用构造果断拒收**：对主线有兜底价值的严格技术补证（如连续极限正核补证）放到附录，正文给 1–2 句精炼索引；对全文毫无用处的极端防杠建议，不硬塞进正文，交付时向用户说明取舍理由。
4. **改后文风回检**：所有修改落地后，必须通读改过的章节，确认没有删掉原有玩具例、手算锚点和路标框，也没有长出成段的防御性文字墙。

## 9. 对照实例（A–D 防过简，E–G 防过重）

### 实例 A（防过简）：推导不许外包

**旧**（跳步 + 证据代号）：
> 把双模凝聚写为 $\Psi_\sigma(x)=u_\sigma e^{ik^*x}+v_\sigma e^{-ik^*x}$。直接展开密度与自旋密度（[C2]）得到仅有的非零傅里叶分量 $\rho_{2k^*}=\bm u\cdot\bar{\bm v}$，……

**新**：
> 把双模凝聚写为
> $$\Psi_\sigma(x)=u_\sigma e^{ik^*x}+v_\sigma e^{-ik^*x},\qquad u,v\in\mathbb C^2.$$
> 我们要问：这样的凝聚会在哪些波矢上产生密度调制？密度是
> $$\rho(x)=\sum_\sigma\bar\Psi_\sigma(x)\Psi_\sigma(x).$$
> 代入双模形式，按 $e$ 指数逐项整理：
> $$\rho(x)=\sum_\sigma\Big[\,|u_\sigma|^2+|v_\sigma|^2+\bar v_\sigma u_\sigma\,e^{2ik^*x}+\bar u_\sigma v_\sigma\,e^{-2ik^*x}\Big].$$
> 交叉项是仅有的振荡项。所以密度只有 $0$ 与 $\pm2k^*$ 三个傅里叶分量，其中
> $$\rho_{2k^*}=\sum_\sigma u_\sigma\bar v_\sigma.$$
> 这意味着：CDW 波矢锁定在 $2k^*$ 不是额外假设，而是双模展开的直接代数结果——只要 $\pm k^*$ 两个分量同时非零，$2k^*$ 调制就自动出现。（脚本验证放脚注。）

### 实例 B（防过简）：长句拆开，数学上行间

**旧**（一句话五个论断、全部内联）：
> 对的横向爬行通道中残留一个不可消去的 $(-1)$，使有限动量配对几乎不耗能：$4\times4$ 团簇上两空穴基态在 $t/J\in[1,2]$ 携带总动量 $\bm K=(\pi,\pi)$，在 $t/J=3$ 与 $\Gamma$ 准简并（$\Delta E\simeq0.02J$）；且局域近邻单态对场几乎只产生 $(\pi,\pi)$ 分支——AFM 波矢被印刻在配对场上，这就是 PDW 的两体种子。

**新**：
> 第 X 节证明了：对的横向爬行通道中残留一个不可消去的 $(-1)$。它的直接后果是，把对从零动量推到有限动量几乎不需要能量。数值上，$4\times4$ 团簇的两空穴基态在 $1\le t/J\le2$ 时携带总动量
> $$\bm K=(\pi,\pi);$$
> 在 $t/J=3$ 时它与 $\bm K=\Gamma$ 的态几乎简并：
> $$\Delta E=E(\Gamma)-E(\pi,\pi)\simeq0.02\,J.$$
> 换句话说，有限动量配对与零动量配对在能量上打平。进一步，局域近邻单态对场（定义见式 (x.y)）几乎只产生 $(\pi,\pi)$ 分支。这意味着 AFM 的波矢被直接印刻在配对场上——这正是 PDW 在两体层面的种子。

### 实例 C（防过简）：符号首次出现即定义

**旧**（$n(\bm k)$、$K_G$ 从未定义）：
> 单玻色子扇区。$n(\bm k)$ 在非公度动量 $\pm\bm Q_0$ 出现锐峰；准凝聚，$K_G\simeq0.40$–$0.57$。

**新**：
> 先定义诊断量。单玻色子动量分布是
> $$n(\bm k)=\frac1N\sum_{ij}e^{i\bm k\cdot(\bm r_i-\bm r_j)}\langle \hat B^\dagger_{i\sigma}\hat B_{j\sigma}\rangle,$$
> 凝聚（或准凝聚）表现为 $n(\bm k)$ 在凝聚动量处的峰。单玻色子关联的幂律指数 $K_G$ 由长距离行为定义：
> $$G_\sigma(r)=\langle\hat B^\dagger_\sigma(r)\hat B_\sigma(0)\rangle\sim r^{-K_G},$$
> $K_G$ 越小相干性越强（$K_G\to0$ 对应真长程序）。DMRG 给出：$n(\bm k)$ 在非公度动量 $\pm\bm Q_0$ 出现锐峰，且
> $$K_G\simeq0.40\text{–}0.57,$$
> 即准凝聚。

### 实例 D（防过简）：文字论断马上跟公式

**旧**：
> 扇形凝聚不携带单态分量。

**新**：
> 扇形凝聚不携带单态分量：对扇形取 $u=(a,b)$、$v=(\bar b,\bar a)$，最近邻键上的单态振幅为
> $$\Delta_s^{\rm bond}\propto\big(|a|^2-|b|^2\big)\sin k^*\ \xrightarrow{\ |a|=|b|\ }\ 0.$$
> 所以“单态通道死亡”不是额外输入，而是扇形结构的推论。

### 实例 E（防过重）：直觉即严格，拒绝无意义的四重指标展开

**旧**（为了“严密”硬写半页下标，反而把简单物理埋没）：
> 设 $\{|h\rangle\}_{h=1}^N$ 为已占子空间 $F$ 的一组正交归一基，记 $f_h=\langle h|f\rangle,\, g_j=\langle j|g\rangle$。将 $c[g]c[f]|F\rangle$ 展开为 $\sum_{h,j=1}^N f_h g_j\, c_j c_h |F\rangle$，再对模方做四重指标求和 $\sum_{h,j,h',j'} f_{h'}^* g_{j'}^* f_h g_j \langle F|c_{h'}^\dagger c_{j'}^\dagger c_j c_h|F\rangle$，利用反交换关系 $\delta_{jj'}\delta_{hh'}-\delta_{jh'}\delta_{hj'}$ 展开整理得 $\|c[g]c[f]|F\rangle\|^2 = \det G$……（而下文其实只用到“至少一条轨道空着就得零”）。

**新**（3 行无指标几何分解——既是直觉又 100% 严格）：
> 空轨道里无电子可拿，真正干活的只有两个波包落在已占空间 $F$ 里的投影 $P_F f$ 与 $P_F g$：
> $$c[g]\,c[f]\,|F\rangle = c[P_F g]\,c[P_F f]\,|F\rangle.$$
> 在 $F$ 内把 $P_F g$ 拆成平行于 $P_F f$ 与垂直于 $P_F f$ 的两部分：$P_F g = \alpha\,P_F f + g_\perp'$。平行部分因泡利不相容 $c[P_F f]^2 = 0$ 直接消去，只剩下两条正交已占轨道：
> $$\bigl\|c[g]\,c[f]\,|F\rangle\bigr\|^2 = \|P_F f\|^2\,\|g_\perp'\|^2 = \|P_F f\|^2\|P_F g\|^2 - \bigl|\langle P_F f \mid P_F g\rangle\bigr|^2.$$
> 几何上，这就是两个影子张成平行四边形的面积平方：面积为零当且仅当至少一条轨道本来就空着（$P_F f=0$ 或 $P_F g=0$），或者两个影子共线（试图从同一条轨道掏两次电子）。
>
> *进一步剪裁*：如果整篇报告下文甚至连这个面积公式都用不到、只用到“波包垂直于已占空间即得零”，就干脆连范数公式一起删掉，留三句直觉判据即可。
